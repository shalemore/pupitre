<h1 align="center">Pupitre</h1>

<p align="center"><em>Pupitre，法语词，指教授讲演时摊开讲义的斜面讲桌。</em></p>

[![CI](https://github.com/shalemore/pupitre/actions/workflows/ci.yml/badge.svg)](https://github.com/shalemore/pupitre/actions/workflows/ci.yml) [![License](https://img.shields.io/github/license/shalemore/pupitre)](LICENSE)

![Pupitre 同时编辑法文、俄文和阿拉伯文文档](docs/banner.png)

一款跨平台的 Markdown 编辑器。输入时排版即时呈现，光标所在处的语法依然可见、可改。[在浏览器中试用](https://shalemore.github.io/pupitre/)。

- **Markdown 语法完整呈现。** GFM、front matter、GitHub 提示块、数学与化学公式、Mermaid 图表、脚注、emoji、高亮、上下标，以及行内 HTML。
- **主题就是 CSS。** 每个主题都有明暗两套配色，任意两个主题都能搭配使用。

## 安装

从 [Releases](https://github.com/shalemore/pupitre/releases) 下载，或在 Windows 上用 [Scoop](https://scoop.sh) 安装：

```sh
scoop bucket add shalemore https://github.com/shalemore/scoop-bucket
scoop install pupitre
```

_网页版无法打开文件夹，关闭标签页后文档也不会保留。_

## 功能

- 专注模式与打字机模式
- 代码块语法高亮
- 从右到左与双向混排的文字
- 经典与沉浸式两种窗口样式
- 三十多种界面语言

帮助 › 示例 Markdown 文档展示了支持的语法，以及如何编写主题。
