# Посібник із Pupitre

![Pupitre](./logo.svg)

Pupitre — це настільний редактор Markdown. Документи — звичайні файли `.md`: те, що ви бачите, відображається на місці, а синтаксис Markdown з'являється там, де стоїть курсор. Цей посібник також є зразком того, що відображає редактор; редагуйте його вільно, він зберігається лише після вибору **Зберегти як**.

## Редагування

Поставте курсор у **жирний текст**, `вбудований код` або [посилання](https://github.com/shalemore/pupitre), і навколо нього з'явиться синтаксис. Маркери поводяться як текст:

- Видаліть маркер, щоб зняти форматування; додайте або видаліть `#` перед заголовком, щоб змінити його рівень.
- У виділеному тексті видно його розмітку, а копіювання копіює Markdown.
- <kbd>Ctrl</kbd>+клацання відкриває посилання: веб-адреси відкриваються в браузері, посилання `#заголовок` прокручують до заголовка, а посилання на файл Markdown поруч із документом відкривають його.
- Форматування є в меню **Абзац** і **Формат**, у контекстному меню та в наведених нижче комбінаціях.

## Режими письма

- **Режим зосередження** затемнює все, крім абзацу, у якому ви пишете.
- **Режим друкарської машинки** тримає рядок, який ви пишете, посередині вікна або ближче до його верху чи низу, як задано в Параметрах › Редактор.

Обидва є в меню **Вигляд** і в Параметрах › Редактор, і їх можна поєднувати.

## Стиль вікна

Параметри › Вигляд › Стиль вікна перемикає між **Класичним** і **Імерсивним**. В імерсивному стилі документ розташований на картці всередині вікна; рядок заголовка й бічні панелі ховаються, щойно ви починаєте писати чи прокручувати, і повертаються, коли вказівник досягає верхнього або бокового краю вікна. Закріплені бічні панелі залишаються відкритими, а перетягування краю панелі змінює її ширину.

## Файли та зображення

- Pupitre зберігає закінчення рядків відкритого файлу, якщо Параметри › Markdown не вказують інше. Там само задається розмітка, яку вставляють команди форматування.
- Вставлені зображення зберігаються в теці поруч із документом (типово `assets`, Параметри › Markdown). Незбережений документ тримає їх у пам'яті й записує під час першого збереження.
- Параметри › Загальні › Стандартна програма Markdown змушує Pupitre відкривати файли `.md` з файлового менеджера.
- Параметри зберігаються в `settings.json`; Параметри › Про програму показує його теку. Записуються лише значення, що відрізняються від стандартних, а поле, яке не вдається прочитати, повертається до стандартного без впливу на інші.
- У папки можуть бути власні параметри: коли папку відкрито, у параметрах з'являється перемикач між **Загальні** та **Ця папка**. Зміни в розділі **Ця папка** записуються до `.pupitre/settings.json` у ній; файл створюється під час першої зміни й накладається на загальні параметри, доки цю папку відкрито. Скидання параметра там повертає його загальне значення.

## Теми

Тема визначає стиль усього вікна й документа. Параметри › Вигляд перелічують їх із кольоровими схемами, які вони підтримують, і для темного режиму можна вибрати окрему тему.

Теми постачаються разом із програмою: кожна тема — це тека в `src/renderer/themes/<назва>/` з `index.css`, і назва теки є назвою теми. Шрифти або зображення, які використовує тема, лежать у тій самій теці й на них посилаються відносними `url()`.

```css
:root {
  /* Кольорові схеми, які підтримує тема: світла, темна або обидві */
  color-scheme: light dark;

  /* Типовий шрифт основного тексту; його можна змінити в налаштуваннях */
  --font-document: Georgia, serif;

  /* Дизайн-токени, що діють для всього вікна */
  --ui-surface-1: oklch(0.99 0.01 90);
  --ui-brand: oklch(0.55 0.12 250);
}

@media (prefers-color-scheme: dark) {
  :root {
    --ui-surface-1: oklch(0.2 0.01 90);
  }
}

.md-document .md-h1 {
  font-size: 2em;
}
```

- Кольори задаються токенами `--ui-*` (поверхні, текст, акцент) і `--syntax-*` для коду. Їхні стандартні значення та повний список є в `src/renderer/app.css` і темі `pupitre`.
- Смуги цитат мають використовувати `var(--alert-color, …)`, щоб попередження зберігали свої кольори.
- Розмір основного тексту, міжрядковий інтервал і ширина вмісту належать користувачеві й завжди перемагають; використовуйте `em` для розмірів у документі та логічні властивості, як-от `padding-inline-start`, щоб текст справа наліво дзеркалився.

## Довідник із Markdown

### Текст

**Напівжирний**, _курсив_, ~~закреслений~~, `вбудований код`, [посилання](https://commonmark.org), H~2~O, x^2^, ==виділення==, :tada: і <kbd>Esc</kbd>. Вбудований HTML відображається, коли є повним елементом, інакше показується як вихідний код. Абзац, що містить лише `[TOC]`, перетворюється на список заголовків документа.

```typescript
}
```
