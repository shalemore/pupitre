# دليل Pupitre

![Pupitre](./logo.svg)

Pupitre محرر Markdown لسطح المكتب. المستندات ملفات `.md` عادية: ما تراه معروض منسقًا في مكانه، وتظهر صياغة Markdown أثناء وجود المؤشر عليها. هذا الدليل نموذج لما يعرضه المحرر أيضًا؛ عدّله بحرية، فلن يُحفظ ما لم تختر **حفظ باسم**.

## التحرير

حرّك المؤشر داخل **نص غامق** أو `مقطع برمجي` أو [رابط](https://github.com/shalemore/pupitre) فتظهر صياغته حوله. تتصرف العلامات كأنها نص:

- مفتاح Backspace بعد علامة الفتح مباشرة يزيل التنسيق.
- في بداية العنوان، اكتب `#` لرفع مستواه واضغط Backspace لخفضه.
- التنسيق متاح في قائمتَي **فقرة** و**تنسيق** وفي قائمة السياق والاختصارات أدناه.

## أوضاع الكتابة

- **وضع التركيز** يعتّم كل شيء عدا الفقرة التي تكتبها.
- **وضع الآلة الكاتبة** يُبقي السطر الذي تكتبه في منتصف النافذة.

كلاهما في قائمة **عرض** وفي التفضيلات › المحرر، ويمكن الجمع بينهما.

## نمط النافذة

يبدّل التفضيلات › المظهر › نمط النافذة بين **كلاسيكي** و**غامر**. في النمط الغامر يوضع المستند في بطاقة داخل النافذة؛ يتنحى شريط العنوان والمخطط عند الكتابة أو التمرير ويعودان عندما يصل المؤشر إلى أعلى النافذة أو إلى حافتها الأولى.

## الملفات والصور

- يحتفظ Pupitre بنهايات الأسطر في الملف الذي فتحه ما لم يحدد التفضيلات › Markdown غير ذلك. وهناك أيضًا يُحدَّد كيف تُكتب القوائم والتأكيد وأسوار الشيفرة والفواصل عند الحفظ.
- تُحفظ الصور الملصقة في مجلد بجانب المستند (`assets` افتراضيًا، التفضيلات › Markdown). أما المستند الذي لم يُحفظ بعد فيُبقيها في الذاكرة ويكتبها عند أول حفظ.
- يجعل التفضيلات › عام › تطبيق Markdown الافتراضي برنامج Pupitre يفتح ملفات `.md` من مدير الملفات.
- تُخزَّن التفضيلات في `settings.json`؛ ويعرض التفضيلات › حول مجلده. تُكتب فقط القيم المختلفة عن الافتراضية، وأي حقل يتعذر قراءته يعود إلى قيمته الافتراضية دون التأثير في بقية الحقول.

## السمات

تنسّق السمة النافذة كلها والمستند. يسردها التفضيلات › المظهر مع أنظمة الألوان التي تدعمها، ويمكن اختيار سمة مستقلة للوضع الداكن.

تأتي السمات مع التطبيق: كل سمة مجلد في `src/renderer/themes/<name>/` يحوي `index.css`، واسم المجلد هو اسم السمة. تُوضع الخطوط أو الصور التي تستخدمها السمة في المجلد نفسه وتُشار إليها بمسارات `url()` نسبية.

```css
:root {
  /* أنظمة الألوان التي تدعمها السمة: فاتح أو داكن أو كلاهما */
  color-scheme: light dark;

  /* الخط الافتراضي لنص المتن، ويمكن تغييره من التفضيلات */
  --font-document: Georgia, serif;

  /* رموز التصميم المستخدمة في النافذة بأكملها */
  --ui-surface-1: oklch(0.99 0.01 90);
  --ui-brand: oklch(0.55 0.12 250);
}

@media (prefers-color-scheme: dark) {
  :root {
    --ui-surface-1: oklch(0.2 0.01 90);
  }
}

.milkdown .ProseMirror h1 {
  font-size: 2em;
}
```

- تُضبط الألوان عبر رموز `--ui-*` (الأسطح والنص والتمييز) و`--syntax-*` للشيفرة. قيمها الافتراضية وقائمتها الكاملة في `src/renderer/app.css` وسمة `pupitre`.
- ينبغي أن ترسم أشرطة الاقتباس بـ `var(--alert-color, …)` لتحتفظ التنبيهات بألوانها.
- حجم خط النص وارتفاع السطر وعرض المحتوى تخص المستخدم وتتغلب دائمًا؛ استخدم `em` للأحجام داخل المستند وخصائص منطقية مثل `padding-inline-start` لينعكس النص من اليمين إلى اليسار.

## مرجع Markdown

### النص

**غامق** و_مائل_ و~~يتوسطه خط~~ و`شيفرة مضمنة` و[روابط](https://commonmark.org) وH<sub>2</sub>O وx<sup>2</sup> و<kbd>Esc</kbd> و<mark>تمييز</mark>. يُعرض HTML المضمّن عندما يكون عنصرًا كاملًا، ويظهر كنص مصدري فيما عدا ذلك.

> اقتباس.
>
> > اقتباس متداخل.

> [!WARNING]
> يجب أن تكون العلامة في السطر الأول من الاقتباس.

### القوائم

1. مرقمة
   - متداخلة نقطية
   - [x] يمكن تحديد المهام
   - [ ] وإلغاء تحديدها
2. يمكن أن تحوي القوائم شيفرة:

   ```sh
   npm run dev
   ```

### الشيفرة

```typescript
function countWords(text: string): number {
  const segmenter = new Intl.Segmenter(undefined, { granularity: "word" });
  return [...segmenter.segment(text)].filter((part) => part.isWordLike).length;
}
```
